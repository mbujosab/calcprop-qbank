#+TITLE: qbank — generador de bancos de preguntas de opción múltiple
#+OPTIONS: toc:nil num:nil

[[https://mybinder.org/v2/gh/mbujosab/calcprop-qbank/main?urlpath=lab/tree/ejemplosManual][https://mybinder.org/badge_logo.svg]]

Genera variantes de preguntas de opción múltiple cuyas respuestas correctas se
determinan automáticamente mediante cálculo proposicional. Combina supuestos e
ítems de respuesta por combinatoria, calcula la veracidad o falsedad de cada
ítem según las hipótesis activas y exporta el resultado a LaTeX (AMC) o Moodle
(XML vía LaTeX).

Construido sobre [[https://github.com/mbujosab/calcprop][=calcprop=]].

* Instalación

#+begin_src bash
pip install calcprop calcprop-qbank
#+end_src

Con soporte para el editor visual en Jupyter:

#+begin_src bash
pip install "calcprop-qbank[jupyter]"
#+end_src

* Crear un banco de preguntas

La forma recomendada de empezar es la plantilla de proyecto que se distribuye
con el paquete (desde la versión 0.6.0; con una versión anterior, instala
desde el repositorio: =pip install git+https://github.com/mbujosab/calcprop-qbank=):

#+begin_src bash
qbank-init mi-banco
cd mi-banco
make lint          # comprueba las preguntas de ejemplo (sin LaTeX)
make amc           # PDF de revisión (vista profe) en build/amc/
#+end_src

El proyecto contiene cuatro preguntas de ejemplo en =preguntas/=, los scripts
que las exportan a AMC y Moodle, un =Makefile= (=lint=, =tabla=, =amc=,
=amc-student=, =moodle=, =clean=, filtro =LECCION=N=) y =nueva_pregunta.py=, un
guion para escribir una pregunta en Python y guardarla como JSON. Su
=README.org= explica el flujo.

* Uso rápido

#+begin_src python
from qbank import *

p = ProblemaTipo(
    [
        "Sea $f$ una función ",
        [   # mundos alternativos: en cada variante se sortea uno
            Supuesto("estrictamente creciente", v('crec')),
            Supuesto("estrictamente decreciente", v('decr')),
        ],
        " y sean $a < b$. Entonces:",
        [   # hueco 1: el alumno ve una de estas dos
            Cuestion("$f(a) < f(b)$", v('crec')),
            Cuestion("$f(a) > f(b)$", v('decr')),
        ],
        Cuestion("$f(a) = f(b)$", False),              # hueco 2: siempre
        [   # hueco 3
            Cuestion("$f(b) - f(a) > 0$", v('crec')),
            Cuestion("$f(b) - f(a) < 0$", v('decr')),
        ],
    ],
    export={"last_choice": True},   # + «Ninguna de las anteriores»
)

for etiqueta, partes in p.por_partes():
    for enunciado, cuestiones in partes:
        print(f"Variante {etiqueta}: {enunciado}")
        for texto, correcto, activa, exp in cuestiones:
            print(f"  {'✓' if correcto else '✗'} {texto}")
#+end_src

Ocho variantes (pocas para un banco real: =lint= lo avisa), cada una con tres
opciones más la opción por defecto («Ninguna de las anteriores», correcta solo
si las otras tres son falsas). Una *lista* de =Cuestion= sortea una por
variante; el alumno ve tantas opciones como elementos-Cuestion consecutivos
haya (=GuiaDiseno.org= lo explica).

* Características

** Generación combinatoria de variantes

=ProblemaTipo= toma una lista de supuestos y cuestiones (cada uno con su semántica
proposicional) y genera todas las combinaciones posibles. Para cada variante
calcula automáticamente qué ítems son verdaderos y cuáles falsos. Las variantes
con hipótesis incoherentes o precondiciones insatisfechas se descartan.

El método =por_partes_profe()= muestra todas las cuestiones de cada hueco
(marcando las rechazadas por su precondición en vez de descartar la variante),
facilitando la revisión del banco.

** Preguntas multi-parte

La misma lista plana de componentes admite varias partes: cada vez que tras un
bloque de cuestiones aparece texto o un =Supuesto= se abre una parte nueva. Es
útil para preguntas AMC con múltiples apartados o para el formato cloze de
Moodle. El método =por_partes()= devuelve, por variante, un par
=(enunciado, cuestiones)= por parte:

#+begin_src python
from qbank import *

p = ProblemaTipo([
    "Suponga que ",
    [Supuesto("$A$ es verdadero, ", v("A")),
     Supuesto("$B$ es verdadero, ", v("B"))],
    "¿Cuál es el valor de $A$? ",
    [Cuestion("Verdadero.", v("A")), Cuestion("Falso.", -v("A"))],
    "¿Cuál es el valor de $B$? ",
    [Cuestion("Verdadero.", v("B")), Cuestion("Falso.", -v("B"))],
])

for etiqueta, partes in p.por_partes():
    for enunciado, cuestiones in partes:
        ...
#+end_src

(=ProblemaMultiParte= y =SubPregunta= siguen existiendo por compatibilidad,
pero están deprecados y devuelven un =ProblemaTipo= equivalente.)

** Preguntas paramétricas con =setup=

El parámetro =setup= (código Python, como cadena) se ejecuta antes de cada
variante; sus variables se interpolan en los textos con =@{variable}= y
están disponibles en =ns= para semánticas y precondiciones escritas como
=lambda=:

#+begin_src python
p = ProblemaTipo(
    ["Sean $a = @{a}$ y $b = @{b}$. Entonces:",
     [Cuestion("$a + b = @{suma}$", True),
      Cuestion("$a + b = @{suma_falsa}$", False)],
     [Cuestion("$a + b > 10$", "lambda ns: ns['a'] + ns['b'] > 10"),
      Cuestion("$a + b < 10$", "lambda ns: ns['a'] + ns['b'] < 10")],
     Cuestion("$a \\cdot b = @{producto}$", True)],
    setup="import numpy as np\n"
          "a, b = (int(x) for x in np.random.randint(1, 10, 2))\n"
          "suma, suma_falsa, producto = a + b, a + b + 1, a * b",
    seed=1, export={"last_choice": True, "instances": 15},
)
#+end_src

Con =seed= la pregunta es reproducible e =instances= fija cuántas
realizaciones numéricas se generan (aquí 4 variantes × 15 = 60, el mínimo que
recomienda =lint= con =setup=).

** Persistencia en formato JSON

Guarda y carga problemas (=ProblemaTipo=, =ProblemaVF=) sin reescribir el
código Python:

#+begin_src python
from qbank import load_problema, save_problema

p = load_problema('mi_problema.json')
save_problema(p, 'copia.json')
#+end_src

Para bancos de múltiples problemas: =load_banco= / =save_banco=.

** Editor visual en Jupyter

=ProblemaTipoEditor= es un formulario interactivo (requiere =ipywidgets=) que
permite construir, previsualizar y guardar problemas sin escribir código:

#+begin_src python
from qbank import ProblemaTipoEditor

editor = ProblemaTipoEditor()           # editor vacío
editor = ProblemaTipoEditor('p.json')  # cargar desde fichero

p = editor.to_problema()               # obtener el ProblemaTipo
#+end_src

Ver [[https://github.com/mbujosab/calcprop-qbank/blob/main/Manual.org][Manual.org]] si los widgets se muestran como texto en lugar del formulario.

** Exportación a AMC y Moodle

*** Formato AMC (LaTeX)

Función de bajo nivel que devuelve un bloque LaTeX listo para escribir al
fichero:

#+begin_src python
with open("preguntas.tex", "w") as f:
    for etiqueta, partes in p.por_partes():
        for enunciado, cuestiones in partes:
            f.write(AMCblock("MiCuestionario", etiqueta, enunciado, cuestiones))
#+end_src

Vista aplanada para el profesor (todas las cuestiones con marcas):

#+begin_src python
n = QuizAMCProfe("MiCuestionario", "exportaciones/", p)
print(f"{n} bloque(s) escritos")
#+end_src

Para preguntas multi-parte, =AMC_multipart(nombre, etiqueta, "", partes,
last_choice=…, cols=…)= produce un único =questionmult= con un bloque de
casillas por parte.

*** Formato Moodle (XML vía LaTeX)

#+begin_src python
# Vista alumno
n = QuizMoodle("MiCuestionario", "exportaciones/", p, last_choice=True)
print(f"{n} variante(s) escritas")

# Vista profe (fracciones de puntuación visibles)
QuizMoodleProfe("MiCuestionario", "exportaciones/", p)

# Con paquete LaTeX adicional y texto comodín personalizados
QuizMoodle("MiCuestionario", "exportaciones/", p,
           aux_latex=r"\usepackage{nacal-moodle}",
           last_choice_text="Las demás opciones son falsas")
#+end_src

=QuizMoodle= y =QuizMoodleProfe= devuelven un =int= con el número de variantes
escritas, útil para logging en scripts de build.

Para preguntas =ProblemaVF=: =QuizVFMoodle=.

** Exportación a código Python editable

=save_problema_py= genera un fichero =.py= con la definición del problema como
listas editables:

#+begin_src python
from qbank import save_problema_py

save_problema_py(p, 'mi_problema.py')
#+end_src

El fichero resultante puede abrirse con cualquier editor, modificarse y
ejecutarse directamente con Python.

** Comprobación automática de preguntas (=lint=)

=lint= revisa un problema (objeto, dict o ruta a JSON) sin modificar nada ni
compilar LaTeX y devuelve una lista de =Aviso(nivel, codigo, mensaje, donde)=
con nivel =ERROR=, =AVISO= o =INFO=:

#+begin_src python
from qbank import lint, tabla_mundos

for a in lint("preguntas/L-01-ejemplo.json"):
    print(a)
print(tabla_mundos("preguntas/L-01-ejemplo.json"))   # Cuestion × mundo
#+end_src

Desde la línea de órdenes (código de salida 1 si hay algún =ERROR=):

#+begin_src bash
python -m qbank.lint preguntas/*.json [--instances N] [--seed S] [--tabla] [--quiet]
qbank-lint preguntas/*.json --quiet      # equivalente; omite INFO y ficheros OK
#+end_src

Comprueba, entre otras cosas, la garantía de mezcla (=1 <= correctas <=
opciones-1= en toda variante, contando la opción por defecto de =last_choice=),
el número de variantes, negaciones =-v('X')= que nunca podrían deducirse por
falta de un =unoDe(...)=, interpolaciones =@{var}= sin resolver, etiquetas
huérfanas, la estructura del JSON y caracteres que rompen la exportación a
Moodle. La tabla de mundos muestra el valor de cada =Cuestion= en cada
combinación de =Supuesto= (=V=, =F= o =-= si la rechaza su =precond=), para
localizar distractores constantes.
