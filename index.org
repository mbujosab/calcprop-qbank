[[https://mybinder.org/v2/gh/mbujosab/calcprop-qbank/main?urlpath=lab/tree/Tutorial.ipynb][https://mybinder.org/badge_logo.svg]]

Genera variantes de preguntas de opción múltiple cuyas respuestas correctas se
determinan automáticamente mediante cálculo proposicional, y exporta el
resultado a LaTeX (AMC, exámenes en papel) o a Moodle (XML vía LaTeX).

Es para profesores que quieren un banco de preguntas con muchas variantes de
cada una, todas corregidas automáticamente, sin tener que comprobar a mano
qué opción es correcta en cada variante.

* Instalación

Dentro de un entorno virtual:

#+begin_src bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install calcprop-qbank       # instala también calcprop
#+end_src

y después, para crear un banco con cinco preguntas de ejemplo:

#+begin_src bash
qbank-init mi-banco
cd mi-banco
make lint          # comprueba las preguntas de ejemplo (sin LaTeX)
make amc           # PDF de revisión (vista profe) en build/amc/
#+end_src

El Manual (sección «Instalación paso a paso») lo explica despacio, también
para Windows.
