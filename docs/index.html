qbank — generador de bancos de preguntas de opción múltiple

Genera variantes de preguntas de opción múltiple cuyas respuestas correctas se determinan automáticamente mediante cálculo proposicional, y exporta el resultado a LaTeX (AMC, exámenes en papel) o a Moodle (XML vía LaTeX).

Es para profesores que quieren un banco de preguntas con muchas variantes de cada una, todas corregidas automáticamente, sin tener que comprobar a mano qué opción es correcta en cada variante.

Instalación

Antes de empezar hace falta:

  • Python 3.9 o superior.
  • GNU make (en Windows, desde Git Bash, MSYS2 o WSL).
  • LaTeX, solo para los PDF y el XML de Moodle: sin él se pueden escribir y comprobar preguntas con make lint y make tabla.
  • El programa Auto Multiple Choice, solo si vas a usar exámenes AMC.

Los detalles, en los requisitos del README del banco.

Dentro de un entorno virtual: 

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install calcprop-qbank       # instala también calcprop

y después, para crear un banco con cinco preguntas de ejemplo: 

qbank-init mi-banco
cd mi-banco
make lint          # comprueba las preguntas de ejemplo (sin LaTeX)
make amc           # PDF de revisión (vista profe) en build/amc/

Instalar Python y crear el entorno virtual paso a paso, también en Windows: «Instalación paso a paso» del Manual. make y LaTeX en Windows y macOS: requisitos del README del banco. Cómo importar el XML en Moodle (tras make moodle): paso «Exporta» del flujo de trabajo del README del banco.

Qué leer, en este orden

  1. README (HTML): qué hace qbank, cómo instalarlo y crear un banco con qbank-init, y un recorrido rápido por sus características.
  2. Tutorial (abrir en MyBinder, sin instalar nada; verlo en GitHub): cinco ejemplos progresivos ejecutables. Es un cuaderno Jupyter y se puede saltar: sin cuadernos, el camino es README → Guía → Manual, trabajando en el proyecto que crea qbank-init.
  3. README del banco (HTML): el que qbank-init deja en cada proyecto. Qué hay en el proyecto, el flujo de trabajo con make, cómo leer la vista profe, los caracteres que rompen la exportación y cómo llevar las preguntas a un examen AMC o a Moodle.
  4. Guía de diseño (HTML, PDF): cómo diseñar buenas preguntas: la mecánica de listas y mundos, el patrón de tres huecos + opción por defecto, setup, redacción de cuestiones y explicaciones, trampas de LaTeX/Moodle y checklist. Las palabras que usa toda la documentación (hipótesis, mundo, variante, hueco, parte, opción por defecto, vista profe…) están en su Vocabulario.
  5. Manual (HTML, PDF): referencia completa de la API y del formato JSON.
